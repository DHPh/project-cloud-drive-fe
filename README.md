# Frontend

Frontend dự kiến dùng Next.js App Router, TypeScript, Tailwind, Heroicons React và TanStack Query. Mục tiêu đầu tiên là giữ bố cục Drive của bản Nuxt và hoàn thành [DRIVE-01](../docs/use-cases.md#drive-01--mở-thư-mục-và-thao-tác-tệp).

- [Thiết kế UX](docs/ux.md)
- [Hợp đồng API](../docs/contracts/README.md)
- [Kiểm chứng và bàn giao](../docs/verification.md)

Thư mục đang ở giai đoạn tài liệu. Bổ sung lệnh cài, chạy, typecheck và kiểm thử khi khởi tạo app.
